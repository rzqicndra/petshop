# Aset dan lisensi pihak ketiga

- Font Plus Jakarta Sans dan DM Serif Display disertakan lokal. Salinan SIL Open Font License tersedia di `static/fonts/*-OFL.txt`.
- Foto ilustrasi berasal dari Unsplash, dibawa dari prototype sebelumnya. Foto tidak mewakili lokasi, pegawai, atau pelanggan Sinau Satwa. Sumber rinci ada di `static/images/photo-sources.json` dan `asset-sources.json`; ketentuan: <https://unsplash.com/license>.
- Ilustrasi SVG kemasan pada seed dibuat khusus sebagai data contoh di proyek ini. Ganti dengan foto serta informasi produk resmi sebelum penjualan nyata.
- Logo paw/wordmark adalah identitas antarmuka awal; konfirmasikan dengan pemilik usaha.
- Framework/library memakai lisensi masing-masing. Pin dependensi berada pada `requirements.lock`.
- Lisensi distribusi kode milik proyek belum ditetapkan di sini; tentukan bersama pemilik proyek sebelum membuka repository secara publik.
